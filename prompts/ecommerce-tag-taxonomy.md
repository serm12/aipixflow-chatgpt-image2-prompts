# E-commerce Tag Taxonomy

Use the English `slug` in prompt JSON data and database records. Use the
Chinese or English label for UI display.

Rules:

- Every E-commerce prompt should include 2-5 tags.
- The first tag is the primary product category.
- Use only the slugs listed below.
- Prefer product/category tags over visual-style tags.
- Use scenario tags only when useful for filtering.
