## What Is This?

AIPixFlow ChatGPT Image 2 Prompts is a curated dataset of AI image prompts and demo
images for commercial creative generation. The current release focuses on
e-commerce product ads, product main images, apparel model shots, and social
media cover/post templates.

All records use stable category names and controlled tag slugs so the dataset
can be imported into apps, CMS systems, marketplaces, and prompt galleries.

## Data Formats

- `prompts/prompts.json`: full prompt dataset.
- `prompts/ecommerce-tag-taxonomy.json`: controlled e-commerce tag taxonomy.
- `prompts/ecommerce-tag-taxonomy.md`: readable tag reference.
- `prompts/system-prompt-en.md` and `prompts/system-prompt-zh.md`: optional generation guidance.

Prompt records include:

```json
{
  "id": "demo-gptimage-ecommerce-fashion-city-trench",
  "prompt": "4:5 vertical e-commerce fashion main image...",
  "model": "gptimage",
  "categories": ["E-commerce"],
  "tags": ["apparel", "womenswear", "product-main-image"],
  "image": "https://aipixflow-assets.shopupup.com/prompts/.../0.png",
  "author_name": "AIPixFlow"
}
```
