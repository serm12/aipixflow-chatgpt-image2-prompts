## 项目介绍

这是 AIPixFlow 整理的一套 AI 图片提示词与演示图数据集，当前重点覆盖
电商商品广告、商品主图、服装模特展示、社交媒体封面和内容模板。

数据里统一使用稳定的分类名和 tag slug，方便后续导入网站、CMS、素材库、
提示词库或电商创意工具。

## 文件结构

- `prompts/prompts.json`：完整提示词数据。
- `prompts/ecommerce-tag-taxonomy.json`：电商 tag 白名单。
- `prompts/ecommerce-tag-taxonomy.md`：中英对照 tag 文档。
- `prompts/system-prompt-en.md`、`prompts/system-prompt-zh.md`：可选提示词生成规范。
